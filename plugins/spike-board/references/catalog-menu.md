# Catalog menu — the fixed block every skill pastes

Paste the block between the markers **exactly as written** wherever a skill offers the
catalog as a menu. Don't regroup, reorder, abbreviate, annotate, or convert it to
prose — the point is that every mentee sees the identical menu every time. When the
catalog gains or loses a topic, change this file in the same commit as
`topic-catalog.md`.

Tags: `· Aware` marks topics that deliberately stop at Aware depth; `· N-step track`
marks topics whose exit questions are assigned per step (one step = one spike).
